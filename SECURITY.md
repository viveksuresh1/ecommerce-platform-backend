# Security Policy

If you discover a security vulnerability in this project, please do not open an issue.

## Reporting

Send an email to: `security@your-domain.example` (replace with a real address if/when you publish this repo).

## What to include

- Description of the vulnerability
- Steps to reproduce (if possible)
- Impact assessment
- Proposed fix/workaround (optional)

## Response

We will acknowledge receipt and provide an ETA for next steps.
