# Contributing

Thank you for your interest in contributing to this project.

## How to contribute

1. Fork the repository
2. Create a feature branch (`blackboxai/your-branch-name` or `feature/…`)
3. Make changes
4. Add/adjust tests (if applicable)
5. Update documentation (README/docs) when behavior or APIs change
6. Open a Pull Request

## Development rules

- Keep changes focused and easy to review.
- Follow existing code style and patterns.
- Prefer small PRs over large ones.

## Pull Requests

Use the PR template and include:
- summary of changes
- why the change is needed
- how it was tested
